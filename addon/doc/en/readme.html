Claude Desktop Access

An NVDA add-on for Claude Desktop on Windows. It closes Claude's side panels with one keyboard shortcut, without hovering with the mouse and without searching for the Close button.

Commands

Keyboard commands
KeysAction
Ctrl+Shift+JCloses a panel. See "Which panel closes" below.
NVDA+Ctrl+Shift+JWrites diagnostics to the NVDA log. Use it when a panel is open but the add-on does not find it.

Both commands can be given other keys in NVDA's Input Gestures dialog, under "Claude Desktop Access".

Which panel closes

What Ctrl+Shift+J does
When you press itWhat happens
The focus is inside a panel: the artifact panel, Session details or a split viewThat panel closes.
The focus is outside the panels, for example in the prompt or the chat, and one panel is openThat panel closes.
The focus is outside the panels and two or more panels are openA list of the open panels opens. Enter closes the selected panel and Escape closes the list.
No panel is openNVDA announces "No panel to close".

The Browser panel shows a web page of its own, so the add-on cannot tell from inside it which panel the page belongs to. When the focus is in the Browser panel and other panels are open too, the list opens with Browser already selected, so Enter closes it.

After a panel closes, NVDA announces "Closed" and the name of the panel, and the focus returns to where it was before you entered the panel.

Panels the add-on knows

  • Panels with a Close button, such as the artifact panel, the Browser panel and split views.
  • Session details, which has no Close button. The add-on presses its toggle button, "Session rail", in the "Session tools" toolbar.

Requirements

NVDA 2026.1 or later, tested with NVDA 2026.2. Claude Desktop for Windows. The add-on works only while Claude has the focus.

Known limits

  • The Terminal, Changes and Files toggle buttons have not been tested as a way to close their panels.
  • After Session details closes, the focus is not moved back.
  • If Claude changes the structure of its interface, the add-on may stop finding a panel. NVDA+Ctrl+Shift+J then shows in the log what NVDA sees.

What is written to the NVDA log

Each use of Ctrl+Shift+J writes one line with counts and times only. NVDA+Ctrl+Shift+J writes the roles of the elements around the focus, and names only for Claude's own toolbars, regions, toggle buttons and close buttons. It never writes document titles, session names or text from the page.
